# G-Code Assembler frontend

This React app provides the G-Code Assembler upload page and interactive STL viewer. It expects the Flask backend from [`../Backend/flask_back.py`](../Backend/flask_back.py) to be running at `http://localhost:5001`.

From this directory, run `npm install` once, then `npm start` to open the frontend at `http://localhost:3000`. For backend setup, project details, and limitations, see the [repository README](../README.md).
